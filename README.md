# Caudal en el móvil

Web instalable (PWA) para consultar y apuntar movimientos de Caudal desde el móvil.

- Abre la contabilidad (.caudal) desde Dropbox; los datos nunca pasan por aquí.
- Lo que se apunta va a la bandeja de Dropbox y lo contabiliza Caudal en el ordenador.

Esta carpeta es la web ya compilada (`npm run build:movil` en el proyecto CAUDAL, carpeta `src/mobile`).
